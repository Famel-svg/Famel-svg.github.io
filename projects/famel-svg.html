.github/workflows/cards.yml
name: Atualizar cartões do perfil

on:
  schedule:
    - cron: "0 6 * * *"
  workflow_dispatch:
  push:
    paths:
      - scripts/build_cards.py
      - scripts/festive.py

permissions:
  contents: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: python scripts/build_cards.py
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      - name: Commit se mudou
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "41898283+github-actions[bot]@users.noreply.github.com"
          git add assets/*.svg
          git diff --cached --quiet || (git commit -m "chore: atualizar cartões do perfil" && git push)

O workflow inteiro. O cron roda às 06:00 UTC; o git diff --cached --quiet evita commit vazio, então o histórico só cresce quando um cartão muda de fato.The whole workflow. The cron runs at 06:00 UTC; git diff --cached --quiet prevents empty commits, so the history only grows when a card actually changes.

scripts/festive.py
def festive_event(d):
    """Evento festivo da data, ou None para cair no sorteio normal."""
    md = (d.month, d.day)
    if md == (12, 31) or md == (1, 1):
        return "anonovo"
    if (12, 20) <= md <= (12, 25):
        return "natal"
    if (10, 25) <= md <= (10, 31):
        return "halloween"
    if (6, 12) <= md <= (6, 29):
        return "junina"
    p = easter(d.year)
    if p - timedelta(days=50) <= d <= p - timedelta(days=46):  # sábado de carnaval até quarta de cinzas
        return "carnaval"
    if p - timedelta(days=2) <= d <= p:  # sexta-feira santa até domingo
        return "pascoa"
    return None

Usado em scripts/build_cards.py, linhas 125-126: festive_event(date.today()) tem prioridade; se devolver None, o sorteio com semente fica com o dia. easter() calcula a Páscoa com o algoritmo de Meeus/Jones/Butcher.Used in scripts/build_cards.py, lines 125-126: festive_event(date.today()) comes first; if it returns None, the seeded draw decides the day. easter() computes Easter with the Meeus/Jones/Butcher algorithm.

scripts/build_cards.py
def stats_card(user):
    repos = user["repositories"]
    rows = [
        ("Contribuições no último ano", user["contributionsCollection"]["contributionCalendar"]["totalContributions"]),
        ("Commits no último ano", user["contributionsCollection"]["totalCommitContributions"]),
        ("Repositórios públicos", repos["totalCount"]),
        ("Pull requests", user["pullRequests"]["totalCount"]),
        ("Estrelas recebidas", sum(r["stargazerCount"] for r in repos["nodes"])),
    ]
    body = [f'  <text x="28" y="78" fill="{BLUE}" font-family="{FONT}" font-size="15">$ git stats --author rafael</text>']
    for i, (label, value) in enumerate(rows):
        y = 112 + i * 28
        body.append(f'  <text x="28" y="{y}" fill="{SOFT}" font-family="{SANS}" font-size="15">{escape(label)}</text>')
        body.append(f'  <text x="440" y="{y}" fill="{INK}" font-family="{FONT}" font-size="15" font-weight="700" text-anchor="end">{value}</text>')
    return frame(470, 112 + len(rows) * 28, "stats", "\n".join(body))
