o problemathe problem

Quando abastecer com etanol compensa no bolso? A regra dos 70% diz que compensa quando o litro do etanol custa até 70% do preço da gasolina. O projeto usa essa regra como critério e aplica SQL a preços reais da ANP no Rio de Janeiro.When does filling up with ethanol pay off? The 70% rule says it does when the ethanol price per litre is at most 70% of the gasoline price. The project uses this rule as a criterion and applies SQL to real ANP prices in Rio de Janeiro.

combustiveis-sql-analytics/sql/05_regra_70_etanol.sql
-- Query 5: em quais município-semanas o etanol compensa pela regra de 70%.
-- Compara o preço médio semanal do etanol com o da gasolina no mesmo município e semana.
-- Compensa quando etanol <= 70% da gasolina. Só entram semanas com os dois produtos.
-- Achado descritivo: não prova causa. Ver README, seção Limites.
WITH semanal AS (
    SELECT
        municipio,
        produto,
        ano_iso,
        semana,
        MIN(data)            AS inicio_semana,
        ROUND(AVG(preco), 3) AS preco_medio
    FROM precos_rj
    WHERE produto IN ('ETANOL', 'GASOLINA')
    GROUP BY municipio, produto, ano_iso, semana
),
par AS (
    SELECT
        municipio,
        ano_iso,
        semana,
        MIN(inicio_semana) AS inicio_semana,
        MAX(CASE WHEN produto = 'ETANOL'   THEN preco_medio END) AS etanol,
        MAX(CASE WHEN produto = 'GASOLINA' THEN preco_medio END) AS gasolina
    FROM semanal
    GROUP BY municipio, ano_iso, semana
    HAVING COUNT(DISTINCT produto) = 2
)
SELECT
    municipio,
    inicio_semana,
    etanol,
    gasolina,
    ROUND(100.0 * etanol / gasolina, 1) AS relacao_pct,
    (etanol <= 0.70 * gasolina)         AS etanol_compensa
FROM par
ORDER BY etanol_compensa DESC, relacao_pct ASC, municipio, inicio_semana;

A consulta mostra em quais município-semanas o etanol ficou até 70% da gasolina. O resultado é descritivo: não prova causa, como o README registra na seção de limites.The query shows the municipality-weeks where ethanol was at most 70% of gasoline. The result is descriptive: it does not prove cause, as the README notes in its limits section.

combustiveis-sql-analytics/sql/04_ranking_municipios_rank.sql
-- Query 4: ranking de municípios por preço médio do período, com RANK.
-- RANK dá a mesma posição para empates e pula o número seguinte (1, 1, 3).
-- Ranking 1 = município mais barato para aquele produto.
WITH media_periodo AS (
    SELECT
        municipio,
        produto,
        ROUND(AVG(preco), 3) AS preco_medio,
        COUNT(DISTINCT ano_iso * 100 + semana) AS n_semanas  -- chave única da semana ISO
    FROM precos_rj
    GROUP BY municipio, produto
)
SELECT
    produto,
    municipio,
    preco_medio,
    n_semanas,
    RANK() OVER (
        PARTITION BY produto
        ORDER BY preco_medio ASC
    ) AS posicao_mais_barato
FROM media_periodo
ORDER BY produto, posicao_mais_barato, municipio;

O ranking usa média simples por município. Um município com poucas coletas pode ter média distorcida; o README recomenda usar o ranking como ponto de partida.The ranking uses a simple average per municipality. A municipality with few records can have a distorted average; the README suggests using the ranking as a starting point.
